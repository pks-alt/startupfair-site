# StartupFair Website

This package contains the complete source code and public assets for the StartupFair website.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.

## Production build

Run `npm run build`.

## Current hosted website

https://startupfair-ai-challenges.pksamal.chatgpt.site

The website forms are currently prototype interactions. A production form-processing service and secure storage must be connected before accepting real submissions.
